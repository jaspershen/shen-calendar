A LITTLE MORE HEADSPACE.

Make room for what matters.

Shen Calendar is a personal deadline planner. Keep upcoming commitments in one place, see how much time remains, and notice unfinished work before it slips away.

Use it for proposals, assignments, appointments, travel preparations or everyday follow-ups. Each task has a precise deadline, an optional priority, and space for notes and images.

01 · Get started in a minute

  1. Open the Deadline board and select Add task.
  2. Enter a task name and a deadline, including the time. Choose a priority and add any notes you need.
  3. Select Save task. Your task appears with a countdown and a deadline status.
  4. When finished, select the completion control beside the task and confirm. You can find it again under Completed.

You can start without an account. For access from another device, register and sign in, then use Import browser tasks to copy existing local tasks into your account.

02 · Create and manage tasks

Names, deadlines and priorities

Give each task a clear name, such as “Submit grant proposal.” Deadlines include a date and time, down to the minute. The editor shows your device’s local time zone. Priority can be High, Normal or Low; priority is separate from how soon the deadline arrives.

Notes and images

Add instructions, links or next steps in Notes. In the task list, notes are collapsed by default: select Show notes to read them and Hide notes to collapse them.

Paste a screenshot into the Notes field with Cmd+V on Mac or Ctrl+V on Windows, or select Add images. Attach up to three images per task. PNG, JPG, WebP and GIF files are accepted; images are resized and converted to compressed JPEG, so animation and transparency are not retained. Each source file must be no larger than 15 MB. Remove an attachment in the editor, or select a saved thumbnail to view it at a larger size.

Edit, complete, reopen or delete

Select Edit to change task details. Complete marks a task as finished; Reopen makes it active again. Both actions ask for confirmation. Delete also asks for confirmation and permanently removes the task. Canceling a confirmation leaves the task unchanged.

03 · Choose your view

Deadline board

The board combines a summary, today’s briefing and a task list. Select Due today, Due within 3 days or another summary count to filter the list. The third reminder window defaults to seven days; enter a different number and select Apply.

Timeline

Each row represents one task and each column represents a day. A diamond marks the deadline. The colored span shows the interval between today and the deadline, including overdue time; it does not represent estimated work duration or a task’s start date. Choose a 30-, 60- or 90-day range and use the arrows or Today to navigate. Select a task to edit it. On small screens, the timeline uses compact task cards.

Calendar

Use the monthly calendar to see which days contain deadlines. Navigate between months and select a task to edit its details.

Search and combine filters

Switch between Active, Completed and All. Search matches task names and notes. Combine Due days, Overdue and Priority to narrow the results. Filters work together, so a combination can return no tasks. Select Reset filters, clear the search, or clear an active summary filter to widen the results.

04 · Read deadlines and reminders

Keep the page open for reminders.

Shen Calendar updates countdowns while it is open. It does not send email, push or background notifications when the page is closed.

Deadline colors for unfinished tasks
StatusColorMeaning
OverduePurpleThe deadline has passed. Remaining time is negative, for example −15h 26m.
Due todayRedThe deadline is later today in your device’s local time.
Due within 3 daysOrangeAfter today, but within the next 72 hours.
Due within 7 daysBlueBeyond the three-day window, but within seven days.
LaterGreenMore than seven days remain.
CompletedGrayThe task has been marked as finished.

Summary windows overlap: a task due today can also count toward the three-day and seven-day totals. These upcoming totals exclude completed and overdue tasks. The configurable reminder window affects its summary and filter; the standard status colors keep their three-day and seven-day thresholds.

Unfinished overdue tasks remain in the overdue reminder area until you complete them, change their deadlines or delete them. Older date-only tasks use 23:59. Deadlines are interpreted in the current device’s local time zone; check their times if you travel or change device time zones.

05 · Accounts, storage and privacy

Without signing in

Your tasks and attached images are stored in this browser’s local storage on this device. Another person opening the website on their own device does not receive those tasks. Anyone using the same browser profile on your device may be able to see them. Clearing site data, switching browsers or using a private window can make local tasks unavailable.

With an account

Select Sign in / Register to create an account with an email and password. Follow the email confirmation instructions if prompted, then sign in. Use Forgot password? to request a reset email. Google sign-in is available only when enabled by the site owner; a disabled “coming soon” button means it is not yet available.

Signed-in tasks and images are saved in the project’s Supabase database under your account. Database access policies restrict users to their own calendar records. Other users signing into their own accounts do not see your tasks. On shared devices, sign out when finished.

Browser tasks and account tasks are separate. Import browser tasks copies local tasks into the signed-in account, skips matching task IDs and keeps the browser copy. Signing out returns you to that browser’s local tasks.

Using more than one device

Sign in with the same account to load your saved tasks. Changes are saved to the cloud, but open tabs do not receive live updates from other devices. Refresh before continuing work on another device. If the site reports a conflicting update, reload and review the latest tasks before trying again.

Check the storage status and any save-error messages. An unsuccessful save should not be treated as a saved change. Images consume storage too; export backups regularly.

06 · Import calendars and keep backups

Import an Outlook or other calendar

  1. Export your calendar from Outlook, Google Calendar or Apple Calendar as an iCalendar (.ics) file. Export options depend on your calendar app and organization’s settings.
  2. Select Import calendar in Shen Calendar and choose the file (up to 5 MB).
  3. Review the preview. Uncheck events you do not want and read any warnings about skipped items.
  4. Select Import selected to append the chosen items to your current browser or account calendar.

Timed events use their start time as the task deadline; all-day events use 23:59. Supported time-zone information is converted to the device’s local time during import. Existing matching imported items are skipped. Recurring entries and other unsupported or canceled items may be skipped; review the warnings and add any missing deadlines manually.

Calendar import is a snapshot.

It is not a live Outlook connection. Later changes in Outlook are not automatically reflected here, and editing a task here does not update Outlook.

Export and restore a backup

Select Export to download a Shen Calendar JSON backup of the current task collection, including notes and images. Store it somewhere safe: it contains your task content.

Select Import to restore a Shen Calendar JSON backup (up to 20 MB). Restoring replaces the current task collection after confirmation, rather than merging it. Export your current tasks first. JSON backups and .ics calendar imports use different buttons and serve different purposes.

07 · Common questions

Why is my task missing?

Check whether you are signed into the expected account. Browser tasks and account tasks are separate. Then select All, clear search and filters, and check Completed. If working across devices, refresh to load the latest saved data.

Will I receive a reminder tomorrow if I close the site?

No. Open the website to review your briefing, countdowns and overdue tasks. Background reminders are not currently supported.

Can I use it on my phone?

Yes. Open the same website in your mobile browser. Sign into the same account to access cloud tasks; unsigned-in browser data stays on its original device.

Why did an image or save fail?

Check the file type and size, wait for image processing to finish, and read the displayed error. Browser storage can fill up, especially with image attachments. Export a backup before removing data. For cloud tasks, check your connection and sign-in state.

Where can I report a problem?

Visit the GitHub issue tracker. Describe what happened and the browser you used. Avoid including private task details, passwords or account credentials in public reports.
